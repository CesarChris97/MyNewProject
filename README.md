# Cesar Ortiz Portfolio Page

Welcome to my professional developer portfolio dashboard. This web application serves as a clean, responsive layout showcasing my technical expertise, engineering projects, and ongoing academic milestones.

## Languages & Libraries Used
* **HTML5:** Used to build a clean, semantic, and accessible structural document foundation.
* **CSS3:** Custom stylesheet rules to implement a cohesive color palette, modern UI components, and card layouts.
* **JavaScript (ES6):** Orchestrates dynamic client-side workflows by checking browser storage states, serializing data structures, and handling asynchronous DOM node injections.

## Dependencies & Infrastructure
* **Deployment & Hosting Engine:** Distributed live globally via **GitHub Pages**.
* **Framework Requirements:** 100% Vanilla architectures. Zero external dependencies or frameworks to ensure lightning-fast performance and clean execution of native browser Web APIs.
